# 文字輸入修正驗證（2026-10-14）

點選輸入欄位時重新啟用文字接收器；再次點選同一欄位也會恢復焦點。Android 僅在編輯欄位時顯示鍵盤，結束編輯時隱藏鍵盤。Windows 保留原有按鍵處理。

網頁封裝允許輸入空白，並將中文組字的提交交由 `compositionend` 處理。組字預覽不寫入資料；相同提交的後續 `input` 不重複插入。橋接程式內嵌於編譯器產生的模組，重新建置不會留下額外的輸出檔案。封裝支援獨立輸入模組及較早的單一 Processing 模組。

## 驗證結果

- Chrome／Playwright：完整瀏覽器整合測試 31 項通過，無頁面錯誤。新增實體鍵盤文字與空白、同一欄位再次聚焦、全選取代、退格、Chrome IME 組字提交一次及接續鍵入測試。
- 資料模型：31 項通過、0 失敗。
- Windows 桌面：21 項通過、0 失敗。測試使用隔離資料夾。
- Android 15（API 35）原生模擬器：啟動時鍵盤隱藏；點選搜尋欄位後顯示；輸入 `hello world` 完整顯示；退格、返回鍵隱藏鍵盤及再次點選同一欄位重開鍵盤正常。另以模擬器的 LatinIME 軟體鍵盤直接點選按鍵，驗證原生輸入法提交。
- 所有 Android 操作均指定 `emulator-5554`，未使用實體手機。API 37 模擬器會在 `vulkan.ranchu.so` 提交畫面時崩潰，因此使用已快取的 API 35 系統映像建立隔離模擬器完成驗證。
- 核心相容修補可套用於 `專案.json` 指定的編譯器基準；補齊網頁及 Android 環境判斷函式。

## 重跑網頁輸入驗證

先建置網頁版，再執行：

```powershell
node 測試/瀏覽器驗證.mjs --文字輸入
```

不帶參數則執行完整瀏覽器測試。檔案選擇測試在設定所選檔案後等待繪圖完成，避免等待尚未關閉的選檔對話框。

本次已重建 `網頁/`、`dist/星泉看板.wasm` 與 `dist/android.apk`。Android APK 保留原套件識別字 `org.aquariuslang.app.p22dc05393bb4f811`。
